# Abdulrahman Binfaris — Academic Website

A static, responsive academic website. No build tools or paid hosting required.

## Publish using GitHub Pages
1. Sign in at https://github.com.
2. Create a public repository named YOURUSERNAME.github.io (use your exact GitHub username).
3. Upload index.html, academic-cv.pdf and .nojekyll from this folder to the repository root. Upload the extracted files, not this ZIP.
4. Commit the files to the main branch.
5. Open Settings > Pages. Choose Deploy from a branch, then main and / (root). Save.
6. Your website will be available at https://YOURUSERNAME.github.io. Publishing can take up to 10 minutes.

Official instructions: https://docs.github.com/en/pages/quickstart

## Edit
Open index.html in a text editor to change content. Replace academic-cv.pdf with your current academic CV using the same filename. The included CV is the concise academic application version; review it before publishing. The website includes selected verified journal papers rather than an unverified full publication list.

The AB monogram is intentional. To add your own photo, replace the monogram element with an img element and add your photo file. Do not add private contact details or documents you do not want public.
